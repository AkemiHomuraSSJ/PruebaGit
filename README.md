Descripción

Proyecto integrador desarrollado en Kotlin para Android, utilizando Jetpack Compose como framework de interfaz de usuario.

Estructura del proyecto

- ui/ - Pantallas y componentes visuales (Composables)
- data/ - Repositorios y fuentes de datos
- model/ - Clases de datos
- viewmodel/ - Lógica de presentación
- utils/ - Funciones auxiliares

Dependencias principales

- androidx.core:core-ktx
- androidx.lifecycle:lifecycle-runtime-ktx
- androidx.activity:activity-compose
- androidx.compose (BOM, ui, ui-graphics, material3, tooling)
